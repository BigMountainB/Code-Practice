# Code-Practice

## 📁 Davis Plumbing website

The Davis Plumbing website project lives in:

**[`Claude/Websites/DavisPlumbing/`](Claude/Websites/DavisPlumbing/)**

That folder contains the entire site — all pages, the design system, assets,
logos, and the build system — along with its own docs:

- **[`Claude/Websites/DavisPlumbing/README.md`](Claude/Websites/DavisPlumbing/README.md)** — full project documentation
- **[`Claude/Websites/DavisPlumbing/HOW-TO-VIEW.md`](Claude/Websites/DavisPlumbing/HOW-TO-VIEW.md)** — how to preview / host the site

### Quick preview

```bash
cd Claude/Websites/DavisPlumbing
npm run serve      # → http://localhost:8080
```

No dependencies to install — the site is static and the preview server is
built in.
